# Сторож (watchdog)

Маленький отдельный скрипт, который следит за основным ботом **снаружи**
(не в России), чтобы уметь сообщить о падении даже тогда, когда причина
падения — сам российский прокси до Telegram (в этом случае сам бот
физически не может пожаловаться на себя).

Раз в `CHECK_INTERVAL_SECONDS` (по умолчанию 180с) стучится на
`http://<сервер>:8080/health` основного бота. Если несколько проверок подряд
не проходят — присылает сообщение в Telegram каждому из `ADMIN_CHAT_ID`.
Когда снова начинает отвечать — присылает «✅ снова работает».

## Деплой на Railway

1. Тот же GitHub-репозиторий, что и у основного бота — при создании сервиса
   в Railway указать **Root Directory: `watchdog`**.
2. Переменные окружения:
   ```
   BOT_TOKEN=тот же токен, что у основного бота
   ADMIN_CHAT_ID=те же chat_id, что в .env основного бота (через запятую)
   HEALTH_URL=http://135.106.182.116:8080/health
   ```
3. Railway сам подхватит `Procfile` и запустит `worker: python main.py`.

Важно: у Railway при выходе в интернет нет проблем с доступом к Telegram
(в отличие от сервера в России), поэтому уведомления дойдут даже когда
прокси у основного бота сломан.
